# HCAI project

Human-Centred AI course project (University of Coimbra, 2026/27): auditing and mitigating demographic bias in a multi-agent LLM hiring pipeline. The proposal is in `proposal/` (IJCAI template, build with `make pdf`); the implementation spec is GitHub issue #1.
